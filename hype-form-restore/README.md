# HYPE FORM / RESTORE Player

Stable public baseline: **v1.5**

Browser-based local video restoration player with:
- Native Frame Presenter for reliable GPU CLEAN OFF playback
- GPU CLEAN restoration controls
- motion-aware 2-sided temporal processing
- Bicubic / FSR upscale modes
- precise seek zoom
- theater and fullscreen modes
- local playback history

Video files are selected locally in the browser. The page itself does not upload the selected media.
