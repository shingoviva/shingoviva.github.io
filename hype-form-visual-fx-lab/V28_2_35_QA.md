## macOS / VideoToolbox limitation

The available execution environment is Linux, so `h264_videotoolbox` cannot be hardware-benchmarked here. The Mac helper explicitly prefers `h264_videotoolbox` on macOS and falls back to `libx264` only when hardware encoding is unavailable.

A real Mac timing comparison must be read from the in-app v28.2.35 Export Profiler after exporting the same project once with Browser and once with Mac Native. This is intentionally visible in the app because FFmpeg cannot accelerate render-heavy frames if `renderOfflineFrame()` dominates.
