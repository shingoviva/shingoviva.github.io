# Mac Fast Export — FFmpeg + VideoToolbox

HYPE FORM / Visual FX Lab v28.2.35 adds an optional native export path for macOS.
The visual frame is still generated by the app's locked `renderProjectFrame()` / `renderOfflineFrame()` path. Only the H.264 encoding stage is moved out of the browser.

## Why this exists

The normal Browser Export uses WebCodecs + Mediabunny. That is portable, but the browser has to render the frame and encode/package H.264 in the same process.

Mac Fast Export uses:

`HYPE FORM final composite -> raw RGBA -> localhost helper -> FFmpeg -> h264_videotoolbox -> MP4`

The helper prefers Apple's VideoToolbox H.264 encoder. If VideoToolbox is unavailable it reports that fact; the application can still use Browser Export.

## First-time setup

1. Install FFmpeg if necessary.
   - Homebrew: `brew install ffmpeg`
2. Double-click `START_MAC_FAST_EXPORT.command`.
3. Keep the Terminal window open.
4. The helper opens Visual FX Lab at `http://127.0.0.1:47832/`.
5. In EXPORT, choose `Auto — Mac Fast when available` or `Mac Fast — FFmpeg / VideoToolbox`.

The helper writes finished files to:

`~/Downloads/HYPE_FORM_EXPORTS/`

## Export Profiler

Mac Fast Export measures four parts independently:

- `RENDER`: source-frame lock + HYPE FORM final composite
- `READBACK`: Canvas -> RGBA readback
- `FEED / ENCODE`: localhost transfer + FFmpeg backpressure
- `FINALIZE`: encoder flush + MP4 finalization

The app shows the last export's phase percentages after completion. This tells us whether future speed work should target HYPE FORM rendering or encoding.

## Safety

- The helper binds only to `127.0.0.1`.
- Export mutation endpoints require a random session token.
- Output paths are generated by the helper; the browser cannot request an arbitrary filesystem path.
- Allowed browser origins are local Visual FX Lab, `file://`, and the official `shingoviva.github.io` origin.

## Compatibility fallback

Browser Export remains intact and is still the fallback path. PNG Alpha / WebM continue to use their existing exporters.
